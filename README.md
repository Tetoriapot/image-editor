# 画像かんたん加工

画像の結合・分割・切り抜き・リサイズ・自由配置・フィルター加工を、ブラウザで行うツールです。

**[ブラウザで使う](https://tetoriapot.github.io/image-editor/)**

## 主な機能

- **画像結合**：縦・横・グリッド配置、画像サイズの統一、余白と背景色の調整。
- **画像分割**：行数・列数を指定した縦横分割。
- **画像編集**：切り抜き、リサイズ、回転、反転、指定色の透過、画像全体の不透明度。
- **画像合成**：キャンバスへの画像配置、レイヤーの移動・変形・並べ替え。
- **画像加工**：色・質感のフィルター、加工前との比較、前面・背面への仕上げ素材の配置。
- 複数素材の選択、一括加工・削除、個別保存とZIPでの一括保存。
- 元に戻す・やり直す、設定プリセット、素材を含む作業ファイルの保存・再開。
- スマートフォン向けの小型プレビュー、読みやすい表示、ヘルプ。

## 使い方

1. 公開サイト、またはダウンロードした `index.html` をブラウザで開きます。
2. モードを選び、PNG・JPEG・WebP画像を追加します。
3. プレビューを見ながら設定を調整し、完成画像を保存します。

インストールやアカウント登録は不要です。アプリ本体はHTML・CSS・JavaScriptのみで、ビルド作業は必要ありません。

### 背景色を透明にする

「画像編集」の「透過」で「指定した色を透明にする」を有効にし、色を指定します。「画像から色を選ぶ」ではプレビューをクリック／タップして指定できます。背景が残る場合は「色の許容範囲」を少しずつ上げてください。同じ色の部分は背景以外も透明になります（人物・物体の自動切り抜きではありません）。

画像全体を半透明にする場合は「画像全体の不透明度」を下げます。PNG・WebPは透明を保持しますが、JPEGは白背景になります。透過設定は画像結合・画像分割・画像加工にも引き継がれ、設定プリセットと作業ファイルに保存できます。

## 設定保存と作業ファイル

- **設定プリセット**：加工設定をブラウザ内に保存します。画像素材は含みません。別のブラウザや端末には自動で引き継がれません。
- **作業ファイル**：画像素材と加工状態を `.image-work.json` として端末に保存します。「設定保存」から開き直せます。
- 元に戻す履歴は作業ファイルに含まれず、ページを閉じると失われます。作業を残したい場合は、ページを閉じる前に作業ファイルを保存してください。
- 作業ファイルは素材合計100MB・500素材・総画素数120MPまでです。端末のメモリによって、扱える大きさはさらに小さくなります。

## プライバシー

選択した画像の加工はブラウザ内で行い、アプリから画像をサーバーへ送信しません。公開サイトを開く際には、サイト配信元との通信が発生します。

作業ファイルには画像素材が含まれます。第三者への共有や、公開リポジトリへの追加にはご注意ください。

## 開発・テスト

Node.jsで次のコマンドを実行できます。追加パッケージは不要です。

```sh
node --check app.js
node tests/core.test.mjs
```

`tests/fixtures/` はテスト専用に生成した画像です。次のコマンドで再生成できます。

```sh
node tests/create-fixtures.mjs
```

GitHub Pagesは `main` ブランチのルートを公開します。アプリ本体は `index.html`・`style.css`・`app.js` の3ファイルです。

アプリを更新して公開する際は、`index.html` のCSS・JavaScript参照に付けた `?v=` の更新識別子も変更してください。古いキャッシュとの混在を防ぎます。
